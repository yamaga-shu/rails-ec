# README

## ローカル開発環境の構築

1. docker container のビルド

```bash
$ bin/rails docker:build
```

2. docker container の立ち上げ

```bash
$ bin/rails docker:up
```

3. docker container の停止/削除

```bash
$ bin/rails docker:down
```
